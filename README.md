## Featured projects

- **[postgres-backup-operator](https://github.com/Xol1ren/postgres-backup-operator)**: Kubernetes operator for zero-disk streaming PostgreSQL backups to S3/MinIO, with retention management and snapshot-in-time recovery.
- **[cloud-native-telemetry](https://github.com/Xol1ren/cloud-native-telemetry)**: low-overhead host observability agent in Go that scrapes `/proc` with zero allocations, with a Prometheus exporter and a FastAPI control plane for incident triage.
- **[syshud](https://github.com/Xol1ren/syshud)**: zero-allocation Linux HUD monitor (10-line TUI) using purego NVML and direct kernel syscalls.
